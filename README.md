 👽 다중 로봇 외계 행성 탐사 시뮬레이션
=============
다중 로봇 자율 협력 시스템을 활용한 외계 행성 탐사 시뮬레이션



<br>


인원 및 기간
-------------
* 3명: [김현아](https://github.com/Hyuna-319), [장석환](https://github.com/JSH0101), [홍유진](https://github.com/dbwls99706)
* 2024.12.17 ~ 2024.12.23 (7일)
  
<br> 

사용 기술
-------------
* Language : Python3
* OS : Linux Ubuntu 22.04 jammy
* Skills : ROS2 Humble, Gazeobo11, Rviz2, Nav2, Turtlebo3 Packages, PyQt5

  
<br>

특징
-------------

* 행성 탐사
  - 달 표면을 기반으로 한 외계 행성 탐사 시나리오 구현
  - 침입자 시뮬레이션을 위한 외계인 캐릭터 배치
  - 탐사 로봇 1 or 2 가 외계인 발견하면 외계인 자율주행

 
<br>

* 우주선 관제 시스템
  - 지도 상 로봇 위치 표시: 로봇1과 로봇2의 위치를 실시간으로 맵에 시각화
  - 

    



보완 사항
-------------
* 미확인 생명체를 발견했을 때 탐사로봇1,2가 우주선으로 복귀
* 외계인은 로봇1 또는 로봇2를 추격하다, 로봇들이 홈으로 복귀하면 초기 위치로 돌아가야함
